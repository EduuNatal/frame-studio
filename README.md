# Frame Studio

Editor de animacao 2D frame a frame que roda inteiro no navegador. Nao precisa de servidor:
o projeto de cada pessoa fica salvo no proprio navegador (IndexedDB) e pode ser exportado em .framestudio.json.

Arquivos: `index.html` (o programa inteiro) e `_headers` (opcional, cabecalhos do Cloudflare Pages).
